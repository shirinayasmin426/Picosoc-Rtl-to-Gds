# Picosoc-Rtl-to-Gds
Complete RTL-to-GDS physical design flow for the PicoSoC core on SkyWater Sky130 (90nm). Covers synthesis, floorplanning, placement, CTS, routing, power integrity, formal equivalence checking, and STA signoff using Cadence Genus, Innovus, Pegasus, Voltus, Conformal LEC &amp; Tempus.
